# Figure scripts

Run scripts from the repository root after generating their input tables; see the [reproduction guide](../README.md).

| Manuscript panel | Script |
|---|---|
| 1C | `figs1_vef_assay_selection.py` |
| 1D | `fig1c_vef_activity_correlation.py` |
| 1E, 1F | `fig1df_activity_correlation_heatmap.py` |
| 1G | `fig1e_dnase_residual_specificity.py` |
| 2A | `fig2a_epicast_scatter.py` |
| 2B, 2C | `fig2bc_activity_metrics.py` |
| 3A | `fig3a_residual_metrics.py` |
| 3B, 3C | `fig3bc_cts_prioritization.py` |
| 3D, 3E | `fig3de_topk_retrieval.py` |
| 3F, 3G | `fig3fg_topk_activity_profile.py` |
| 4A, 4C | `fig4ac_vef_correlation_heatmap.py` |
| 4B, 4D, 4E | `fig4bde_vef_partial_correlation.py` |
| 5A–5E | `fig5_castillo_metrics.py` |

Outputs are PDFs under `paper/figures/`, with separate legends and colorbars where applicable. Script names retain some earlier panel numbering; use the mapping above. Schematic panels are not generated by these scripts.

Figures 2 and 3 use `results/figure_metrics/`, except the scatter and activity-profile panels, which read `results/predictions/`. Figure 4 uses the feature-correlation analyses, and Figure 5 uses `results/castillo/`. Figure 1C requires assay-selection results from `18_vef_assay_selection.py`; other Figure 1 panels read the activity and VEF tables.
